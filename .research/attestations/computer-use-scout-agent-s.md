## Attested details

1. **Full-desktop scope.** Agent S is "an open-source framework designed to enable autonomous interaction with computers through Agent-Computer Interface" — GUI agents that "perform complex tasks autonomously on your computer." Supported platforms: Linux, macOS, and Windows; designed for single-monitor screens. (`README.md`, Introduction and Prerequisites)
2. **Architecture.** The package ships four agent generations (`gui_agents/s1`, `s2`, `s2_5`, `s3`) with a manager/worker decomposition, procedural memory (`memory/procedural_memory.py`), a grounding module that translates agent actions into executable pyautogui-style Python code (`s3/agents/grounding.py`, `OSWorldACI`), and pluggable multimodal engines (`core/engine.py`, `core/mllm.py`). S3 adds a code agent (`agents/code_agent.py`) and Behavior Best-of-N (`bbon/`) with a behavior narrator and comparative judge. (`gui_agents/` layout; `README.md`, Usage)
3. **Model coupling: two-model requirement.** Agent S3 requires both a main generation model (OpenAI, Anthropic, Gemini, Azure, OpenRouter, or vLLM endpoints) and a separate **grounding model** (recommended UI-TARS-1.5-7B, hosted on Hugging Face Inference Endpoints, vLLM, or another provider) with mandatory `--ground_provider`, `--ground_url`, `--ground_model`, and grounding resolution parameters. Recommended pairing: "OpenAI gpt-5-2025-08-07 as the main model, paired with UI-TARS-1.5-7B for grounding." (`README.md`, API Configuration, Grounding Models, Usage)
4. **Execution model and security posture.** The agent "runs Python code to control your computer" via pyautogui with the permissions of the invoking user; the README warns "use with care." An optional `--enable_local_env` coding environment executes arbitrary Python and Bash locally with an explicit warning: "Only use this feature in trusted environments and with trusted inputs"; Bash is limited by a 30-second timeout. No sandbox, permission manifest, or approval mechanism is documented in the fetched source. (`README.md`, Prerequisites, Local Coding Environment Details)
5. **Observability.** The trajectory keeps image turns (`--max_trajectory_length`, default 8) and an optional reflection agent (`--enable_reflection`, default True); grounding is screenshot-based via a grounding model. No structured action log, tracing integration, or recording facility is documented in the fetched README. (`README.md`, Optional Parameters)
6. **Integration surfaces.** Distribution is a Python package (`pip install gui-agents`) with a CLI (`agent_s ...`) and an importable SDK (`AgentS3`, `OSWorldACI`). The `integrations/openclaw/` directory provides an OpenClaw skill plus a Python wrapper (`agent_s_wrapper.py`). No MCP server exists in the repository. (`README.md`, Installation and `gui_agents` SDK; `integrations/openclaw/`)
7. **Local and remote execution.** Runs against the local machine's screen on all three desktop OSes; OSWorld and WindowsAgentArena evaluation harnesses (`osworld_setup/`, `WAA_setup.md`) target VM-based benchmarks. Simular Cloud is offered as a hosted alternative. (`README.md`, Prerequisites, header)
8. **Vendor benchmark claims.** The README reports Agent S3 as "first to surpass human-level performance on OSWorld" at 72.60% (66% in the 100-step setting without Behavior Best-of-N), with WindowsAgentArena and AndroidWorld generalization results; S1/S2/S3 papers are published at ICLR 2025, COLM 2025, and TMLR 2026 respectively. These are vendor-reported results, not independently verified here. (`README.md`, Updates, Current Results)
9. **Grounding-model operational cost.** Pytesseract requires an extra system install (`brew install tesseract`), and the grounding model typically requires running or renting a separate model endpoint (Hugging Face Inference Endpoints or vLLM), in addition to the main LLM API keys. (`README.md`, Installation, Grounding Models)
