## Attested details

1. **Purpose.** `pi-screenshots-picker` is an installable Pi extension for browsing, previewing, selecting, and attaching existing screenshot files to the next prompt on macOS or Linux. (`README.md`, introduction)
2. **User interface.** It provides `/ss`, `/ss-clear`, keyboard shortcuts, terminal thumbnail previews, zoom/pan inspection, source tabs, multi-selection, deletion, and a staged-image widget. (`README.md`, Commands and Features)
3. **Sources.** It auto-detects platform screenshot folders or accepts configured directories and glob patterns. (`README.md`, Configuration)
4. **Boundary.** It does not capture the desktop for the agent or perform computer-use actions. The human or another screenshot utility creates the files; this extension improves attachment workflow only. (`README.md`, Why and Quick Start)
